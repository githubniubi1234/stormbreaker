# Plot style

Figures keep concise titles, axes, units, feature/cohort labels and necessary
legends or statistical annotations. Detailed methods and interpretation belong
in captions rather than small text squeezed into the image.

Direct plots retain explanatory metadata where supported. plots(fit) returns
notes; clinical_plots() returns captions and status. Original IDs, settings,
plot data and validation scopes remain available when display labels are shortened.
Use clinical_plots(run) or plots(fit) without adding a separate style switch.
